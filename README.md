# Task 28 – Simple Percentage Analysis

## Objective
To calculate the percentage contribution of each product category to total sales using Microsoft Excel.

## Dataset
Sample Superstore Dataset

## Tools Used
- Microsoft Excel

## Operations Performed
1. Analyzed sales data by product category.
2. Calculated total sales for each category.
3. Calculated percentage contribution using the formula:

   Percentage Contribution = (Category Sales / Total Sales) × 100

4. Created a percentage analysis table.
5. Created bar and pie charts to visualize category-wise contributions.
6. Verified that the percentages add up to 100%.

## Results

| Category | Contribution |
|---|---:|
| Technology | 36.40% |
| Furniture | 32.30% |
| Office Supplies | 31.30% |
| **Total** | **100%** |

## Conclusion
Technology contributes the highest percentage of total sales, followed by Furniture and Office Supplies.

This task helped me understand percentage contribution analysis and its importance in business reporting and data visualization.
